# Security Policy

## Supported Versions

- `react-class-variants` 2.x: fixes ship in the newest 2.x release, published from `next`.
- `react-tailwind-variants` 1.x (legacy): fixes land on the `v1-maintenance` branch.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Jackardios/react-class-variants/security/advisories/new) and include a minimal reproduction. Do not open a public issue.
